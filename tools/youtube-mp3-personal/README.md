# 私人 YouTube 轉 MP3

此頁只供福建中學鄺劭良老師私人使用，唔係公開 YouTube 轉檔服務。請唔好轉發網址。

正式網址（計劃喺合併後生效）：

https://ksl-blip.github.io/biology-simulators/tools/youtube-mp3-personal/

## 用法

1. 用通行密碼進入（私人閘門，唔係學校登入）。
2. 貼上任意 YouTube 網址，撳「轉換」。
3. 轉換完成後可以喺呢頁播放或下載 MP3。
4. 登入 Google，貼上 Drive 資料夾連結並「儲存資料夾」，然後喺下拉選單選擇資料夾，再上傳。刪除只會移除呢部裝置上嘅清單，唔會刪除 Drive 上嘅實際資料夾。

轉換需要另外運行嘅私人後端（yt-dlp + ffmpeg）。純靜態網頁本身轉唔到 YouTube。若進入時提示伺服器連線失敗，請喺「進階：轉換伺服器網址」填上有效嘅轉換服務網址。

Google Drive 登入用現有嘅網頁應用程式用戶端 ID，授權來源係 `https://ksl-blip.github.io`。請盡量用上面呢個 GitHub Pages 網址做 Drive 上傳。
