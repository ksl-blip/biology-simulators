功課 Google Form 產生器

每次家課複製範本 Google Form，換上今次的語音連結和筆記連結，再得到學生交功課的表格、回應試算表，以及一段 WhatsApp 訊息。真正的程式在 ksl@fss.edu.hk 的 Google 帳戶裡運行。這一頁只負責說明怎樣安裝。

每次你要做的事

  1. 打開已加入書籤的網頁應用程式。
  2. 核對標題（預設是 2029 DSE Biology Homework Submission、今天日期，以及下一個未用過的 a／b／c）。
  3. 貼上今次的語音連結和筆記連結，有需要再加一句說明和截止日期。
  4. 按「產生表單」，複製 WhatsApp 訊息發給學生。

學生仍是閱讀筆記、聽語音，然後在表格上載 PDF。姓名、班別、班號和檔案上載題沿用範本，不會在這裡改掉。

不要把學生資料放進這個網站

這個 GitHub 儲存庫是公開的。學生姓名、學號、功課 PDF 和回應試算表只應留在你的 Google 雲端硬碟。下面的按鈕只複製程式碼。

貼進 Apps Script 的三個檔案

到 script.google.com 用 ksl@fss.edu.hk 開新專案。HTML 檔的名稱必須是 Index。不要貼本頁（小寫的 index.html）。

設定步驟

  1. 專案設定裡勾選顯示 appsscript.json，把三個檔案分別貼上並儲存。
  2. 選函數 getAppState 按執行，用 ksl@fss.edu.hk 授權。若顯示尚未驗證，按「進階」再允許。這是你自己的指令碼。
  3. 部署 → 新增部署 → 網頁應用程式。
  4. 執行身分：我（Execute as: Me）。
  5. 誰可以存取：只有我自己（Who has access: Only myself）。
  6. 部署後把網頁應用程式網址加入書籤。
  7. 第一次打開「範本」，掃描預設表單 1uerPSCadog-u3AsRlM0OR-3mRpJR_GXJCOMlVh75Uvw，指出哪一個網址是語音、哪一個是筆記，然後儲存。資料夾預設是 1I5hvOvxqYWIFXzP1HxlfdWdl7RcacUVF。
  8. 改過程式後：部署 → 管理部署 → 鉛筆 → 新版本 → 部署。書籤網址不用改。

更完整的說明、權限清單和錯誤對照在 README。

程式會幫你做什麼

  • 用雲端硬碟複製範本，放到範本同一個資料夾（或你指定的資料夾），並改標題。
  • 以舊網址的完整字串，取代說明、題目、分節和圖片裡的連結。如果語音是 YouTube，也會更新表單上的影片。
  • 保留 PDF 上載題，並讓新表單接受回應。收集設定不會故意改動。
  • 為這一份功課另建回應試算表。
  • 可以儲存多個範本（不同班別或學年）。產生紀錄留在指令碼屬性，方便再複製。
  • 填了截止日期的話，可以選擇到時自動關閉表單。
