用學校帳戶建立用戶端 ID

      
    
        
  1. 用 ksl@fss.edu.hk 開啟 Google Cloud Console。
    2. 
        
  2. 建立新專案，名稱可以是「功課表單產生器」。
    3. 
        
  3. 啟用 Google Drive API 和 Google Forms API。不用 Picker API，也不用 API 金鑰。
    4. 
        
  4. 「API 和服務」→「OAuth 同意畫面」。使用者類型選 內部 (Internal)。這是 Workspace 內部應用程式，不用經過 Google 驗證。應用程式名稱和支援電郵填你的學校帳戶。
    5. 
        
  5. 「憑證」→「建立憑證」→「OAuth 用戶端 ID」。應用程式類型選 網頁應用程式。
    6. 
        
  6. 已授權的 JavaScript 來源只填 https://ksl-blip.github.io。不要加上網頁路徑。重新導向 URI 可以留空，這個網頁用彈出視窗登入。
    7. 
        
  7. 建立後複製用戶端 ID，貼到上面的欄位並儲存。然後按「用學校帳戶登入」，在帳戶清單選 ksl@fss.edu.hk。
    8. 
      

      
登入時 Google 會要求雲端硬碟和表單的權限。需要完整的雲端硬碟權限，才能按表單 ID 複製你已經擁有的範本，以及讀取資料夾裡現有功課的檔名來決定 a、b、c。如果只用「這個應用程式開啟過的檔案」，程式看不到資料夾裡其他表單，標題會撞名。

    

    

      
這個網頁版做不到的事

      
    
        
  • 不能自動建立或連結回應試算表。產生後請打開編輯頁，按「回應」→「連結至試算表」。
    • 
        
  • 不能把連結縮成 forms.gle。
    • 
        
  • 不能到截止時間自動關閉表單。截止日期只會寫在說明裡。
    • 
      

      
如果學校管理員封鎖 Cloud 專案或第三方應用程式，登入會失敗。那時請改用 Apps Script 做法，在你自己的 Google 帳戶裡部署，不用 Cloud Console。

    

  


  

    
另一種做法

    
不想用 Cloud Console 的話，可以把程式貼進 Apps Script，部署成只有你能開的網頁應用程式。看 Apps Script 設定步驟。學生姓名和功課不要放進這個公開網站；產生紀錄只留在你的瀏覽器。
