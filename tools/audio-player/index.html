管理模式。密碼只係呢部裝置嘅本地鎖，唔係伺服器登入。立即同步、改資料夾、刪除同換檔會經 webhook 叫機器人更新網站檔案。每小時同步由機器人做。網頁入面冇寫入金鑰。

呢部裝置仲有以前上傳、只存在本機嘅錄音。而家播放清單係大家共用，舊檔唔會自動公開。下載之後，用「點樣加入」嘅方法放上網站。

      背景播放用瀏覽器本身嘅聲音播放器。鎖屏之後，系統會顯示播放、暫停同上一首、下一首。播放速度只係記喺你自己部機。

      點樣加入錄音

      播放清單同 mp3 放喺網站檔案入面，所以任何人開 呢條連結 都聽得同同一批。唔使 API 金鑰。網頁唔可以自己上傳：寫入儲存庫要有提交權限，金鑰唔可以放喺瀏覽器入面。

      1. 撳「管理」，用密碼解鎖。未改過密碼時，預設係 admin。可以改 Drive 資料夾，再撳「立即同步」，叫機器人由該資料夾複製 mp3。每小時同步由機器人做。
      2. 喺儲存庫根目錄執行： node tools/audio-player/add-track.mjs 錄音.mp3 --title "標題"
      3. 提交 tracks.json 同 media/ 入面新檔，推上 main。同步都要複製 mp3，唔好只寫 Drive 連結。

      未填 webhook 時，「立即同步」、「儲存資料夾」、「刪除」同「換檔」都會話尚未設定。網址貼喺 sync-config.js。密碼只鎖呢部裝置，詳細步驟喺 tools/audio-player/README.md。

      解鎖管理

      密碼只係呢部裝置上嘅本地鎖，用來收起「立即同步」、「儲存資料夾」、「換檔」同「刪除」。播放唔使密碼。呢個鎖擋唔到直接改瀏覽器儲存資料嘅人。未改過密碼時，預設係 admin。

      密碼唔啱，再試一次。

      更改密碼

      新密碼一樣只係儲存喺呢部裝置，頁面只留 SHA-256 雜湊，唔留明文。清除呢個網站嘅瀏覽器資料會重設做 admin。共享錄音唔會因此刪除。
