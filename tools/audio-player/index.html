課堂語音播放器

錄音由 Google Drive 串流。同一條連結，任何人都聽得同呢批錄音。鎖屏都會繼續播。

Google 阻擋其他網站直接串流 Drive 檔案，所以未填 API 金鑰就播唔到。請喺 sync-config.js 填 driveApiKey：Google Cloud 建立 API 金鑰，只啟用 Drive API，HTTP 參照網址限制做 https://ksl-blip.github.io/*。每個 mp3 仍要設成「知道連結嘅人可以查看」。

呢部裝置仲有以前上傳、只存在本機嘅錄音。而家播放清單係大家共用，舊檔唔會自動公開。下載之後，用「點樣加入」嘅方法放上網站。

      點樣加入錄音

      播放清單只記標題同 Google Drive 連結，mp3 唔會放上呢個網站。任何人開 呢條連結 都串流同一批錄音。網頁入面冇 Drive 或 GitHub 寫入金鑰。

      1. 將 mp3 放進 Drive 資料夾「007 Classroom Audio」，並設成「知道連結嘅人可以查看」。
      2. 撳「同步」，或者喺儲存庫執行： node tools/audio-player/add-track.mjs --drive-id 檔案ID --title "標題"
      3. 同步只更新 tracks.json 嘅連結。提交並推上 main，唔好提交 mp3。

      未填 webhook 時，「同步」會話尚未設定。網址貼喺 sync-config.js。詳細步驟喺 tools/audio-player/README.md。
